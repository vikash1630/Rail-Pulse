# 🚆 RailPulse

RailPulse is an advanced railway analytics and train tracking platform built using real-time Indian Railway data, interactive dashboards, and intelligent data analysis techniques. The platform is designed to simplify railway information by transforming large railway datasets into meaningful visual insights and easy-to-understand analytics.

RailPulse combines modern frontend technologies, backend APIs, and Pandas-powered data analysis to deliver accurate railway information with a smooth and responsive user experience. The platform focuses on real-time train data, train comparison systems, railway performance analytics, and interactive dashboards that help users explore railway insights more efficiently.

🔗 Live Demo: https://rail-pulse-5t74.vercel.app/  
🔗 GitHub Repository: https://github.com/vikash1630/Rail-Pulse

# 🧑‍💻 How To Use

## 1️⃣ Clone The Repository

```bash
git clone https://github.com/vikash1630/Rail-Pulse.git
```

---

## 2️⃣ Navigate Into The Project Directory

```bash
cd Rail-Pulse
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Configure Environment Variables

Create a `.env` file in the root directory.

Example:

```env
VITE_API_URL=your_api_url
MONGODB_URI=your_database_url
JWT_SECRET=your_secret_key
```

---

## 5️⃣ Start The Development Server

```bash
npm run dev
```

---

## 6️⃣ Open In Browser

```bash
http://localhost:5173
```
